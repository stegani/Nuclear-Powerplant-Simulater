# Nucleus: Reactor Simulator

A high-fidelity nuclear power plant management simulation. Balance reactivity, temperature, and pressure to maximize electrical output while avoiding a catastrophic meltdown.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```
   npm install
   ```
2. Start the development server:
   ```
   npm run dev
   ```
3. Open your browser at `http://localhost:3000`

## Build for Production

```
npm run build
```

The static output will be in the `dist/` folder, ready to be served by any web server.
